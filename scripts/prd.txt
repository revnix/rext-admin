# Overview  
Wrext Admin is an AI-powered content management and topic generation platform that enables content creators and marketing teams to generate, manage, and organize high-quality content ideas across multiple industries and platforms. The system combines a sophisticated topic builder wizard with comprehensive content library management, providing users with data-driven topic suggestions powered by LangGraph and multiple AI models.

The platform solves the challenge of consistent, relevant content ideation by offering intelligent topic generation with customizable parameters, audience targeting, and content format optimization. It serves content creators, marketing professionals, social media managers, and businesses looking to scale their content operations efficiently.

# Core Features  
**AI-Powered Topic Builder Wizard:** Multi-step intelligent wizard supporting both subject-first and industry-first content generation flows. Features comprehensive form validation, real-time error handling, and responsive design with 6 configurable steps covering industry selection, audience targeting, content formatting, goals/style preferences, advanced options, and final review/generation.

**Comprehensive Content Library Management:** Full CRUD operations for managing generated topics with advanced filtering, bulk operations, export capabilities (JSON/CSV), and seamless integration between topic generation and library storage. Includes sophisticated data table with sorting, pagination, and search functionality.

**Backend Integration with LangGraph:** Seamless integration with Python-based AI backend featuring LangGraph workflows, multiple LLM providers (OpenAI, Groq, Hugging Face), web scraping capabilities, and PGVector for RAG-enhanced content generation.

**Responsive Design System:** Built on shadcn/ui v3 with Radix UI primitives, featuring comprehensive component library, consistent design tokens, accessibility compliance, and mobile-first responsive patterns.

# Technical Architecture  

**Frontend Stack (Next.js 15+ App Router):**
- Framework: Next.js 15.5.0 with App Router architecture
- UI Library: shadcn/ui v3 + Radix UI primitives
- Styling: Tailwind CSS 4 with custom design tokens
- State Management: Zustand for global state, TanStack Query v5 for server state
- Forms: React Hook Form v7.62.0 + Zod v4.1.5 validation
- TypeScript: Full type safety with comprehensive interfaces
- Testing: Jest + Testing Library with coverage reporting

**Component Architecture:**
- Topic Builder: Modular wizard components with step-based navigation
- Results Management: TopicsList, TopicCard, TopicActions, BulkActions, TopicFilters
- UI Components: Comprehensive shadcn/ui component library
- Layout System: PageLayout, AppSidebar with responsive navigation
- Error Handling: APIErrorBoundary, ErrorAlert with retry mechanisms

**API Integration:**
- Backend Service: Abstract service layer for AI endpoint communication
- Error Classification: Sophisticated error typing and recovery strategies
- Request/Response: TypeScript interfaces for all API contracts
- Headers: Authentication via content-api-key header

**Data Models:**
```typescript
TopicBuilderFormData: Comprehensive form state with 20+ fields
GeneratedTopic: AI-generated topic with scores, metadata, and relationships
TopicGenerationResponse: API response with request tracking and metadata
ValidationResult: Form validation with errors and warnings
```

**Backend Integration Points:**
- Topic Generation: POST /api/generate-topics
- Topic Persistence: POST http://127.0.0.1:2024/api/topic/save-topic
- Topic Retrieval: GET http://127.0.0.1:2024/api/topic/get-topics
- Authentication: content-api-key: supersecretapikey

# Risks and Mitigations  

**Immediate Implementation Risks:**
- Backend Schema Mismatch: GeneratedTopic interface may not align perfectly with save-topic endpoint expectations. Mitigation: Create data transformation layer to map between frontend and backend schemas.
- API Authentication: content-api-key header implementation needs secure handling. Mitigation: Use environment variables and service abstraction layer.
- Error Handling: Save operations may fail silently or with unclear error messages. Mitigation: Implement comprehensive error catching with user-friendly messages and retry mechanisms.

**Data Integration Challenges:**
- Interface Mapping: Backend topic response may not match existing IdeaData interface used in Ideas page. Mitigation: Create adapter functions to transform backend data to frontend interface.
- State Synchronization: Saved topics should appear immediately in Ideas page. Mitigation: Use TanStack Query cache invalidation after successful saves.
- Data Consistency: Generated topics and saved topics may have different field structures. Mitigation: Standardize data models and ensure consistent field mapping.
