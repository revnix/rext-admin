# Overview  
WREXT Admin is a Next.js web application that enables users to generate AI-powered content topics through an intelligent wizard interface and manage them through a comprehensive results system. The application solves the critical problem of content ideation and topic discovery by providing contextually relevant, AI-generated content suggestions tailored to specific industries, audiences, and content goals.

**Target Users:** Content creators, marketers, bloggers, social media managers, and businesses looking to systematically generate high-quality content topics that resonate with their target audience.

**Value Proposition:** Transforms the time-consuming process of brainstorming content ideas into a streamlined, data-driven workflow that produces actionable, scored topics with detailed implementation guidance.

# Core Features  

## 1. TypeForm-Style Topic Builder Wizard
**What it does:** Multi-step, single-question-per-screen wizard that guides users through topic generation parameters
**Why it's important:** Reduces cognitive load and improves completion rates compared to traditional long forms
**How it works:** 
- Dynamic flow based on user selections (subject-first vs industry-first)
- Contextual suggestions based on previous answers
- Real-time validation with smart defaults
- Draft persistence for incomplete sessions

## 2. AI-Powered Topic Generation
**What it does:** Generates contextually relevant content topics with quality scoring and implementation details
**Why it's important:** Eliminates creative blocks and provides data-driven content strategies
**How it works:**
- Integrates with Python/LangGraph backend using multiple LLM providers
- Generates topics with relevance, freshness, and novelty scores
- Provides angle suggestions, audience fit analysis, and implementation rationale
- Uses RAG (PGVector) for enhanced contextual understanding

## 3. Interactive Results Management
**What it does:** Comprehensive topic browsing, evaluation, and management interface
**Why it's important:** Allows users to efficiently evaluate, save, and act on generated topics
**How it works:**
- Simplified card-based layout with essential information
- Topic detail drawer with full metadata and action options
- Optimistic UI updates for seamless user experience
- Local storage integration for topic persistence

## 4. Responsive Mobile Experience
**What it does:** Full-featured mobile interface optimized for touch interactions
**Why it's important:** Enables content creation workflows on mobile devices
**How it works:**
- Adaptive layouts for different screen sizes
- Touch-optimized interactions and gesture support
- Mobile-specific drawer implementations
- Keyboard-aware UI adjustments

# Technical Architecture  

## Frontend Architecture

### Core Technology Stack
- **Framework:** Next.js 15.5.0 with App Router and React 19.1.1
- **Styling:** Tailwind CSS 4.0 with custom design system
- **UI Components:** shadcn/ui 3.0 + Radix UI primitives for accessibility
- **State Management:** Zustand for client state, TanStack Query for server state

# Risks and Mitigations  

## Technical Challenges & Solutions

### High-Risk Areas

#### 1. Multi-Select Input Complexity (High Risk)
**Challenge:** Dual enter-key behavior and chip management could introduce interaction bugs
**Mitigation Strategies:**
- Comprehensive keyboard event testing across all browsers
- Isolated component development with extensive edge case testing
- User testing sessions to validate interaction patterns
- Fallback to simple text input if chip functionality fails
- Progressive enhancement approach with base functionality first

#### 2. State Management at Scale (Medium Risk)
**Challenge:** Complex wizard state with persistence could lead to synchronization issues
**Mitigation Strategies:**
- Zustand middleware testing for persistence edge cases
- State migration strategies for schema changes
- Atomic state updates with clear separation of concerns
- Comprehensive integration testing for state synchronization
- Error boundary implementation for state corruption recovery

#### 3. Topic Detail Drawer Performance (Medium Risk)  
**Challenge:** Large drawer components (60-70% screen width) may impact performance on mobile
**Mitigation Strategies:**
- Lazy loading of drawer content with skeleton states
- Virtual scrolling for large topic lists
- React.memo optimization for topic card rendering
- Bundle splitting to minimize initial load impact
- Performance monitoring and alerting in production
