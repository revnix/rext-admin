# Topic Builder Plan

## Context
The topic builder is a tool that helps users generate topic ideas for their content. It's a wizard-based form that guides users through a series of questions to generate multiple topic ideas.
All these topic ideas then displayed to the user. Then user can save his/her favorite topic ideas to a list.

## What You Need to Do?

I want to replace the existing dummy topic builder with a new and comprehensive and practical topic builder.

For that I want you to make a detailed plan. To make the plan, you need to:
- Analyze the codebase and understand the existing architecture.
- Go through the @wrext-tech-stack.md file and understand the tech stack.
- Go through the @topic-builder-context.md file and understand the context.
- Understand the steps and questions I want to add in the new topic builder from @topic-questions.md file. IMPORTANT: There are two variations for the questions. Please note that, I want to have a Hybrid approach.
- You can see the exact questions, their options, dependencies, optional/advanced questions etc in the @topic-questions.jsonc file.

Write your plan in a markdown file "topic-builder-plan.md".

Make sure to have tasks and subtasks with all the implementation details along with the testing details.

Make sure to follow the tech stack mentioned in the @wrext-tech-stack.md file.

Always analyze the codebase and latest docs of any libraries/packages involved to have the most accurate and up to date information.
